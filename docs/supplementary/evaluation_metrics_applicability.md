# Evaluation Metrics — Applicability Scenarios

Supplementary table for the EPPM SI 14 (AIAM2026) submission
"Comparative Study of Second-Hand Housing Price Prediction Based on Machine Learning
Regression Algorithms: Feature Engineering and Stacking Ensemble Modeling".

| Metric | Formula Characteristic | Outlier Sensitivity | Primary Application |
|---|---|---|---|
| MAE | Linear average of absolute errors | Low | Main metric for model selection, intuitively interpretable |
| RMSE | Square root of squared errors | High | Evaluate the influence of extreme-error samples |
| R² | explained variance ratio | Medium | Assessing model's explanatory power compared to mean baseline |
| MAPE | relative error percent | Medium | Comparison of performance in different datasets and scenarios |
