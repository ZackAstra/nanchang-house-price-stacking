# Nanchang Second-Hand Housing Price Prediction: Feature Engineering and Stacking Ensemble

Companion code and sample data for the manuscript *"Comparative Study of Second-Hand Housing Price Prediction Based on Machine Learning Regression Algorithms: Feature Engineering and Stacking Ensemble Modeling"*.

[中文说明见 README.zh-CN.md](README.zh-CN.md)

## Overview

This repository reproduces the full experimental pipeline of the paper:

- **Data collection**: a four-level crawler for a major Chinese real-estate listing platform (Anjuke, Nanchang) — listing links → listing details → community POI facilities (`main.py`, `src/fetchers/`, `src/parsers/`, `src/storage/`, `config/regions.json`).
- **Feature engineering**: a four-dimensional feature system — physical attributes, POI facilities, geographic accessibility (Accessibility Index), layout structure (Layout Density) — plus a 29-label semantic system annotated from listing titles by keyword rules (`src/research/pipeline.py`).
- **Model comparison**: eight baseline regressors, a Stacking ensemble with a Ridge meta-learner, and an OOF-TSRM two-stage residual model, under a fixed temporally sensitive holdout with community-grouped 3-fold cross-validation (`src/research/run_price_research.py`).
- **Error-diagnosis experiments** (paper §4.4): log transformation, label cleaning dose–response, polynomial interactions, quantile regression, information-ceiling diagnosis (`src/research/*_runner.py`).
- **Semantic feature experiments** (paper §4.5): rule-based vs LLM-extracted labels, including prompt×temperature robustness checks (`scripts/build_llm_batch_jsonl.py`, `scripts/run_qwen_prompt_bridge.py`, `scripts/evaluate_llm_3x2_batch.py`).
- **Analyses**: significance matrix with Holm correction, multi-seed summary, computational cost, descriptive statistics, variance decomposition, sensitivity of constructed indices (`scripts/`).
- **Figures**: all paper figures are regenerated by `scripts/generate_figures_review3.py` and `scripts/generate_shap_beeswarm_review3.py` into `docs/figures/`.

## Headline results (to be verified against `data/expected_outputs/`)

- Final model (log target + rule-based semantic features + StackingRidge): **MAE = 20.17 (×10⁴ CNY), R² = 0.3214** on the extrapolative holdout; R² = 0.68 under a random in-distribution split.
- StackingRidge ranks first in four of five random seeds and significantly outperforms the strongest single model (CatBoost; Holm-corrected p = 4.1 × 10⁻⁷).

## Setup (uv)

```bash
uv venv
uv pip install -r requirements.txt
# crawler only: uv run playwright install chromium
```

## Quick start (smoke run on the bundled samples)

```bash
uv run python -m src.research.run_price_research \
  --houses data/samples/houses_sample.jsonl \
  --communities data/samples/communities_sample.jsonl \
  --output-dir data/runs --run-id smoke --sample-limit 200 --cv-folds 3
```

Metrics from the 200-record sample are only a functionality check. To reproduce the paper's numbers, obtain the full dataset (see below), place it under `data/full/`, and run the same command without `--sample-limit` (keeping `--cv-folds 3`, which matches the paper's community-grouped 3-fold cross-validation).

## Data availability

Following the paper's Data Availability statement:

- **Samples**: 200 stratified records (region × price segment) are bundled under `data/samples/`, including the LLM semantic labels and 10 raw LLM response examples.
- **Aggregate results**: all headline metrics are provided under `data/expected_outputs/` for verification.
- **Full dataset** (7,140 listings; 1,062 communities; full LLM annotations): available from the corresponding author (zhaoxingchen@hotmail.com) upon reasonable request, subject to the original platforms' terms of service. The data were collected from publicly available listing pages and are shared for academic research only.

## Reproducing the paper's tables

The aggregate numbers behind every paper table are shipped in `data/expected_outputs/`. To regenerate them from the full dataset (once it is placed under `data/full/`):

1. Run the pipeline with the paper's CV protocol (community-grouped 3-fold):

   ```bash
   uv run python -m src.research.run_price_research \
     --houses data/full/nanchang_houses.jsonl \
     --communities data/full/nanchang_communities.jsonl \
     --output-dir data/runs --run-id full --cv-folds 3
   ```

2. Copy the three per-sample intermediates that the analysis scripts read:

   ```bash
   cp data/runs/full/cleaned_features.csv data/expected_outputs/
   cp data/runs/full/model_prediction_errors.csv data/expected_outputs/
   cp data/runs/full/model_experiments.jsonl data/expected_outputs/
   ```

3. Run the analysis scripts (each documents its input and output in its header), e.g. `uv run python scripts/descriptive_stats.py`.

File-to-table mapping:

| Paper table / section | File under `data/expected_outputs/` |
|---|---|
| Table 3 descriptive statistics | `descriptive_stats_numeric.csv`, `descriptive_stats_categorical.csv` |
| Table 13 model comparison | `model_metrics.csv` |
| Table 14 voting vs stacking | `voting_vs_stacking_metrics.csv` |
| Table 15 multi-seed stability | `multi_seed_summary.csv` |
| Table 16 error diagnosis | `combined_experiment_summary.csv` (log / cleaning / combined rows) |
| Table 17 semantic features | `stacking_comparison.csv` (semantic rows) + `semantic_logarea_summary.csv` (log-area row) |
| Table 19 significance matrix | `significance_matrix.csv` |
| Table 21 computational cost | `compute_cost.csv` |
| Table 22 index sensitivity | `sensitivity_results.csv` |
| §4.4.4 variance decomposition | `variance_decomposition.csv` |
| §4.5.3 semantic agreement | `semantic_agreement.csv` |

Notes:

- `stacking_comparison.csv` holds the semantic-feature experiment (Table 17), not the Voting-vs-Stacking comparison, which lives in `voting_vs_stacking_metrics.csv`.
- Table 16's remaining rows (moderate / unit-price / total-price cleaning doses, polynomial interactions, quantile regression) are regenerable with the corresponding runners (`label_noise_experiment_runner.py`, `log_transform_experiment_runner.py`, `polynomial_feature_runner.py`, `quantile_regression_runner.py`) but are not pre-shipped.
- The headline results were produced with Python 3.11.10 and the pinned versions in `requirements.txt`; the code also runs on Python ≥ 3.11.

## LLM annotation

Semantic labels were extracted from listing titles with large language models. The three prompt designs (baseline / few-shot / structured-strict) are published verbatim under `llm_prompts/`; annotation used the SiliconFlow asynchronous batch API. Sample annotations and raw responses are under `data/samples/`.
